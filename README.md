# 리센느 유니버스 — 한국어판

일본 팬북 『RESCENEユニバース ― K-POPのどん底から始まった新世界 リセンヌの記録』(名もなきREMINE 지음)의 한국어판 웹 버전입니다.

- 원작: https://pt-knight.booth.pm/items/9197350
- 지은이가 보내 준 한국어 원고를 바탕으로 문장을 다듬었습니다.
- 공개된 기사·방송·통계 자료를 바탕으로 개인이 쓴 비공식 기록입니다. 리센느, 더뮤즈엔터테인먼트 및 관계자와는 관계가 없으며, 영리를 목적으로 하지 않는 무료 배포판입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 첫 화면(소개·내려받기·목차) |
| `chapter-01.html` ~ `chapter-50.html` | 장별 본문 |
| `prologue.html`, `epilogue.html`, `part-1.html` ~ `part-8.html` | 프롤로그·에필로그·부 도입 |
| `characters.html`, `appendix*.html`, `timeline.html`, `sources.html` | 등장인물·부록·연표·출처 |
| `downloads/` | 전편·후편 PDF와 Word 파일 |
| `assets/style.css` | 스타일(라이트/다크 모드 자동) |

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만듭니다. 이름은 `RESCENE-UNIVERSE-KO`(Public).
2. 이 폴더 안의 파일을 모두 저장소 루트에 올립니다(`.nojekyll` 포함).
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 정하고 저장합니다.
4. 1~2분 뒤 `https://scentiment-rs.github.io/RESCENE-UNIVERSE-KO/`에서 열립니다.
6. 검색 노출을 원하면 Google Search Console과 네이버 서치어드바이저에 사이트를 등록하고 `sitemap.xml`을 제출합니다.
